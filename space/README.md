# LindaBench

Este leaderboard lê `../data/` no mesmo repositório. Para abrir localmente, execute
`python -m http.server 8000` na raiz e acesse `http://localhost:8000/space/`.
Para hospedar em outro serviço, publique a raiz do projeto, incluindo `data/`.
